## Summary

The codebase has nearly tripled, to about 23,200 lines of Rust across ten crates, and it is in better shape than at the last review. 26 of the 47 standing findings are fixed, including every P1 and P2 bug except the screenshot tour, and the test suite went from zero tests to 160. The architectural rule that simulation crates never import render or UI still holds, determinism work (#31) made headless runs reproducible, and the energy ledger balances to four decimal places.

The new problems concentrate in three places.

First, **save and load.** A save file that does not parse crashes the app on the first frame after logging "starting fresh"; a loaded session never writes `chronicle.log`; a load restores three `SimStats` counters and resets the rest, so per-cause deaths stop summing to the total and the first Graphs sample after a load spikes by the whole saved run; and in headless mode every warning on that path is swallowed because the headless app has no log plugin. None of this shows in the per-PR reviews because each save PR was locally correct.

Second, **neighbour queries.** Mate search and symbiosis linking accept anything in a 5×5 block of 16-unit hash cells, not within their stated reach, and no neighbour query or distance check wraps across the torus edges that movement and terrain both wrap. These two shape who meets whom, so fixing either changes dynamics and needs an audit.

Third, **death accounting** has a few more holes of the class invariant 4 exists for: a disease death can be revived by a symbiosis transfer later in the same tick, any starvation past age 3000 is filed as old age, and a killed attacker can still kill.

Documentation drift was again widespread (about 35 small markdown edits across README, FEATURES, DECISIONS, ARCHITECTURE, ROADMAP, plans, and TODO). Those were fixed on this branch under the fix-it-now rule. Drift in code comments and help strings is recorded as findings because it needs a code change.
