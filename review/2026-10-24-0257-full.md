## Reproducing the synthetic simulation boundaries

These two findings used an actual `SimPlugin` schedule with a small,
constructed state rather than an evolved seed. To repeat at the reviewed
revision, save the following as a temporary
`crates/clauvolution_sim/examples/review_boundaries.rs`, then run
`cargo run --release -p clauvolution_sim --example review_boundaries`
with Rust 1.98.1. It creates no GUI or user session. Remove that temporary
example after reproducing; it is diagnostic code, not a proposed fix.

The first check starts with no organisms but a species last reconciled at
population 20, then runs 151 fixed ticks. The second adds an age-40,
generation-zero hunter and requests a volcano on a 24-by-16 world, whose
full area lies within the eruption radius. Current assertions capture the
bugs: a repaired implementation should instead report zero living species
with a final extinction, then one Event death in every relevant lifetime
instrument. The original global-cause accounting must remain one.

```rust
use bevy::prelude::*;
use clauvolution_core::*;
use clauvolution_genome::InnovationCounter;
use clauvolution_phylogeny::{PhyloTree, SpeciesStrategy, WorldChronicle};
use clauvolution_sim::SimPlugin;
use clauvolution_world::{TileMap, WorldPlugin};
use std::collections::HashMap;
fn main() {
    let mut app = App::new();
    app.insert_resource(Session::new_ephemeral());
    app.add_plugins((CorePlugin, WorldPlugin, SimPlugin));
    app.insert_resource(Time::<()>::default());
    app.insert_resource(SimConfig { world_width:24, world_height:16,
        max_food_density:0.0, food_regen_rate:0.0, ..SimConfig::default() });
    let mut terrain_rng = SimRng::from_seed(42);
    app.insert_resource(TileMap::generate(24,16,&mut terrain_rng.0));
    app.insert_resource(SimRng::from_seed(42));
    app.insert_resource(InnovationCounter(0));
    app.insert_resource(WorldChronicle::default());
    app.insert_resource(TickCounter(600));
    let mut phylo=PhyloTree::default();
    phylo.record_species(1,None,0,Color::WHITE,SpeciesStrategy::Grazer,None);
    phylo.update_populations(&HashMap::from([(1,20)]),600);
    app.insert_resource(phylo);
    app.world_mut().resource_mut::<SimStats>().species_count=1;
    for _ in 0..151 {
        app.world_mut().resource_mut::<Time>().advance_by(std::time::Duration::from_secs_f64(1.0/30.0));
        app.world_mut().run_schedule(FixedUpdate);
    }
    let world=app.world();
    let node=&world.resource::<PhyloTree>().nodes[&1];
    println!("After 151 real simulation ticks with zero organisms: species_count={}, phylo current_population={}, extinct_tick={:?}",world.resource::<SimStats>().species_count,node.current_population,node.extinct_tick);
    assert_eq!(world.resource::<SimStats>().species_count,1);
    assert_eq!(node.current_population,20);
    assert_eq!(node.extinct_tick,None);
    app.insert_resource(ButtonInput::<KeyCode>::default());
    let mut rng=SimRng::from_seed(9);
    let mut innovation=InnovationCounter(0);
    let mut hunter=clauvolution_genome::Genome::new_minimal(&mut innovation,&mut rng.0);
    hunter.photosynthesis_rate=0.0;
    hunter.diet=0.8;
    app.world_mut().spawn((Organism,Position(Vec2::new(10.0,10.0)),Energy(10.0),EnergyFlows::default(),Age(40),Generation(0),hunter));
    app.world_mut().resource_mut::<Time>().advance_by(std::time::Duration::from_secs(3));
    app.world_mut().resource_mut::<Events<WorldEventRequest>>().send(WorldEventRequest::Volcano);
    app.world_mut().run_schedule(Update);
    let world=app.world();
    let stats=world.resource::<SimStats>();
    let band_deaths: u64=world.resource::<DietBandStats>().deaths.iter().map(|d|d.total()).sum();
    println!("After guaranteed volcano kill of age40 founder hunter: total_deaths={}, Event={}, band_deaths={}, founder_hunter_deaths={}, recorded_lifespans={}",stats.total_deaths,stats.deaths_by_cause[DeathCause::Event as usize],band_deaths,stats.founder_hunter_deaths,world.resource::<FitnessTracker>().recent_lifespans.len());
    assert_eq!(stats.total_deaths,1);
    assert_eq!(stats.deaths_by_cause[DeathCause::Event as usize],1);
    assert_eq!(band_deaths,0);
    assert_eq!(stats.founder_hunter_deaths,0);
    assert_eq!(world.resource::<FitnessTracker>().recent_lifespans.len(),0);

}
```
